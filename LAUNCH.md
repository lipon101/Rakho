# Rakho — Launch & Operations Guide

Everything here runs on the **free tier**. No paid service is required to go live.

## Architecture (already built — don't rebuild)

| Layer | What | Where | Cost |
|-------|------|-------|------|
| Android app | Pharmacy POS / stock / expiry / baki | `android/` | free |
| API + DB | Django REST + PostgreSQL | Render (`render.yaml`) | free |
| Landing + signup | Self-contained HTML in Django | `backend/inventory/landing.py` | free |
| Payments | bKash/Nagad TrxID + manual approve | `/pay/<token>/` + `/admin/` | free |
| Crash reports | Firebase Crashlytics | app, when `google-services.json` present | free |
| Error monitoring | Sentry | API, when `SENTRY_DSN` set | free |
| Uptime / keep-warm | UptimeRobot → `/api/v1/ping/` | external monitor | free |

**Do not add Firebase/Neon/Supabase for auth or the database.** The API key *is* the
login (no passwords to leak or forget), and your Postgres already holds tenants,
subscriptions and the audit trail.

## 1. One-time setup

### Render (API + database)
1. Connect the repo; Render reads `render.yaml` and creates the web service + free Postgres.
2. Set these env vars in the Render dashboard (the rest are already in `render.yaml`):
   - `DJANGO_SECRET_KEY` — auto-generated by render.yaml.
   - `SETUP_TOKEN` — auto-generated; guards the one-time `/api/v1/setup/*` endpoints.
   - `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` — paste your Play service-account JSON (only needed
     for Play billing; leave empty and every pharmacy stays on the free plan safely).
   - `SENTRY_DSN` — from a free sentry.io project (optional but recommended).
   - `PAYMENT_NUMBER` — defaults to **+8801580857515**; only set it to override.
3. Create your admin login (Render → Shell):
   ```
   python manage.py createsuperuser
   ```
   Then sign in at `https://<your-api>/admin/`.

### Landing page
- It is served from your API domain root (`https://<your-api>/`). Nothing else to deploy.
- Optional: put a prettier custom domain or a Netlify/GitHub Pages static mirror in front
  later; the signup form just needs to `POST /api/v1/signup/`.

## 2. Keep Render's free tier awake (the honest way)

Render free instances sleep after ~15 min idle. **Do not self-ping from your own code**
(that violates the ToS). Instead use a real uptime monitor:

1. Create a free account at **UptimeRobot**.
2. Add an **HTTP(S) monitor** → URL `https://<your-api>/api/v1/ping/` → interval **5 minutes**.
   This endpoint returns `204` with no body and never touches the database, so it's cheap
   and legitimate. You also get free downtime alerts as a bonus.

## 3. Money flow (how a customer becomes Pro)

1. Visitor fills the landing form → gets a **free API key** instantly (shown once).
2. They tap **Pro আপগ্রেড** → opens their private `/pay/<token>/` page → it shows
   **Send Money to +8801580857515** for **৳299**.
3. They pay in bKash/Nagad and submit the **TrxID** → lead becomes **"Payment to verify"**.
4. You confirm the TrxID in your own bKash/Nagad app, then in `/admin/` → **Signup requests**
   → select → action **"Approve & activate Pro"**. Their plan flips to Pro for 30 days.

No card gateway, no fees, and nothing auto-grants access without your approval.

### Anti-abuse built in
- **Per-IP rate limits**: signup `10/hour`, payment `30/hour` (attackers can't mass-mint keys).
- **Honeypot field**: bots that fill the hidden `website` input get a fake success, create nothing.
- **Idempotent signup**: the same WhatsApp number re-registering within 15 min gets its existing
  link back instead of a duplicate tenant.
- **TrxID format + uniqueness**: only valid codes accepted; each TrxID can be claimed once,
  so one receipt can't activate multiple accounts (409 on replay).
- **Keys are hashed (SHA-256)** and shown once; the DB never stores the raw key.

## 4. Crash & error monitoring (free)

- **App crashes (Crashlytics):** create a free Firebase project → register the Android app
  (package `com.lipon.rakho`) → download `google-services.json` → drop it at
  `android/app/google-services.json`. The Gradle build auto-enables Crashlytics when the file
  exists; without it the build is unchanged (safe for forks/CI). The file is git-ignored.
- **API errors (Sentry):** create a free sentry.io project → copy the DSN → set `SENTRY_DSN`
  on Render. Errors only, no PII, no performance spans (stays well inside the free quota).

---

## 5. Abuse / trust notes

- Leaked key? Revoke it in `/admin/` → `Pharmacy API keys` → set `revoked_at`. The app for
  that pharmacy immediately gets `401` and prompts to reconnect.
- Every Google Play purchase verification is logged in `PlayPurchaseEvent` (idempotent, so a
  replayed token can never double-grant).
- Admin is the only place plans change by hand — customers can never upgrade themselves.

## Daily ops
- New leads/payments: `/admin/` → **Signup requests**.
- Comp or extend a plan (cash/bank deal): `/admin/` → **Subscriptions**.
- Health check: `/api/v1/health/` (full) and `/api/v1/ping/` (keep-warm).
